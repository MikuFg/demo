# Обувной магазин

Десктопное приложение для управления обувным магазином, разработанное на Python с использованием PyQt6.

## Описание

Приложение предоставляет функционал для:
- Просмотра каталога товаров
- Управления товарами (добавление, редактирование, удаление)
- Управления заказами
- Аутентификации пользователей с разными ролями

## Роли пользователей

- **Гость** — просмотр товаров без возможности редактирования
- **Клиент** — просмотр товаров и создание заказов
- **Менеджер** — управление заказами, просмотр товаров
- **Администратор** — полный доступ: управление товарами, заказами, пользователями

## Технологии

- **Python 3.x**
- **PyQt6** — графический интерфейс
- **SQLite** — база данных

## Установка

1. Убедитесь, что установлен Python 3.x

2. Установите необходимые зависимости:
```bash
pip install PyQt6
```

3. Запустите приложение:
```bash
python main.py
```

## Функционал

### Аутентификация
- Вход в систему с использованием учётных данных
- Автоматическое определение роли пользователя
- Возможность работы в режиме гостя

### Управление товарами
- Просмотр каталога товаров с фотографиями
- Поиск и фильтрация по поставщикам
- Сортировка по возрастанию/убыванию
- Отображение информации о скидках
- Для администраторов: добавление, редактирование и удаление товаров

### Управление заказами
- Создание новых заказов
- Просмотр истории заказов
- Управление статусами заказов

## Особенности интерфейса

- Цветовая индикация товаров:
  - Зелёный фон — скидка более 15%
  - Синий фон — товар отсутствует в наличии
  - Зачёркнутая цена — товар со скидкой

- Двойной клик по товару (администратор) — открытие формы редактирования

## База данных

Приложение использует MySQL базу данных. Структура БД включает таблицы для:
- Пользователей
- Товаров
- Заказов
- Категорий
- Поставщиков
- Производителей
